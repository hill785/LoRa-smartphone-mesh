### What is this?
First smartphone-to-smartphone LoRa mesh where **phone itself is LoRa gateway**.

- No RAK, no MNTD, no dongle
- BLE 5.0 GATT bridge encapsulates LoRaWAN packets
- Store-and-forward DTN mesh (15km hop, 868MHz ISM)
- Multi-backhaul: Helium IoT, GEODNET, Starlink, Eutelsat
- DePIN: HNT + $2/phone reward

### vs Helium
